CARA GUNA PADA IPHONE/ANDROID:
1. Upload SEMUA fail dalam folder ini ke web hosting HTTPS (contohnya GitHub Pages).
2. Buka URL HTTPS melalui Safari (iPhone) atau Chrome (Android).
3. Tekan 'Buka Kamera' dan beri kebenaran kamera.
4. Halakan kamera pada kain/objek, kemudian tap warna sasaran.
5. Tekan Freeze untuk menghentikan frame semasa; atau 'Pilih Gambar'.
6. Copy HEX/RGB/HSL/CMYK (anggaran), atau Simpan dan Export CSV.
7. Pada iPhone, Safari -> Share -> Add to Home Screen.

PENTING: Kamera tidak berjalan dari fail file:// tempatan di iPhone; gunakan hosting HTTPS.
Warna telefon tidak setepat spectrophotometer. CMYK ialah anggaran matematik dan perlu dikawal melalui profil ICC kilang cetakan. Minta bukti cetak atau swatch fizikal.
